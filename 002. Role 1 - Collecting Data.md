# Data Analysis — Role 1: Collecting Data

## 1. What is Data Collection?

Data collection is the process of obtaining the data needed to answer a business, organizational, or analytical question.

A Data Analyst does not simply "find some data." The analyst first determines:

- What question needs to be answered?
- What data is required?
- Where can that data be obtained?
- Is the source reliable?
- Is the data legally and ethically usable?
- How should the collected data be stored and documented?

### Basic workflow

Question → Identify required data → Find data source → Collect / Extract data → Store data → Document source → Process & Clean data

---

## 2. What is Data?

Data is recorded information.

Example:

| Order ID | Date | Product | Quantity | Price |
|---|---|---|---:|---:|
| 1001 | Sep 1 | Keyboard | 2 | $40 |
| 1002 | Sep 1 | Mouse | 1 | $20 |
| 1003 | Sep 2 | Keyboard | 1 | $40 |

A collection of records like this is a dataset.

Common formats:

- CSV
- Excel
- JSON
- SQL database tables
- Parquet
- Google Sheets
- API responses

---

## 3. Main Sources of Data

### 3.1 Internal Data

Data generated and stored inside an organization.

Examples:

- Sales database
- Customer database
- CRM
- Inventory system
- HR system
- Financial system
- Website analytics
- Mobile-app analytics
- Customer-support system

Example:

A company's orders are stored in a SQL database. The Data Analyst can extract the required records using SQL.

```sql
SELECT
    order_date,
    product_id,
    quantity,
    revenue
FROM orders
WHERE order_date >= '2026-09-01';
```

### 3.2 External Data

Data obtained from outside the organization.

Examples:

- Government datasets
- World Bank
- WHO
- UN
- Public APIs
- Research organizations
- Open-data portals
- Financial data providers

External data can be combined with internal company data for analysis.

---

## 4. Primary vs Secondary Data

### 4.1 Primary Data

Data collected directly by you or your organization for a specific purpose.

Examples:

- Surveys
- Questionnaires
- Interviews
- Experiments
- Observations
- A/B tests
- Direct measurements

Example:

A company wants to understand customer satisfaction. It creates a survey and collects responses from 1,000 customers.

This is primary data.

### 4.2 Secondary Data

Data that has already been collected by another organization or person and is reused for analysis.

Examples:

- World Bank datasets
- Government census data
- Public research datasets
- Existing reports
- Open-data portals

Example:

Downloading population data from the World Bank and using it for an analysis.

This is secondary data.

---

## 5. Main Methods of Collecting Data

### 5.1 SQL / Databases

One of the most important methods in real-world Data Analyst jobs.

Company data is often stored in relational databases.

The analyst uses SQL to retrieve the required information.

Important SQL topics:

- SELECT
- FROM
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Aggregate functions
- Subqueries
- CTEs

Example:

```sql
SELECT
    customer_id,
    order_date,
    revenue
FROM orders
WHERE order_date >= '2026-01-01';
```

The result can then be used for further processing and analysis.

---

## 6. APIs

API = Application Programming Interface.

An API allows software to communicate with another software or service and request data.

Example workflow:

API → HTTP request → JSON response → Extract data → Save dataset → Process & analyze

Example response:

```json
{
    "city": "Dhaka",
    "temperature": 31,
    "humidity": 78
}
```

Important API concepts:

- API
- Endpoint
- HTTP
- GET
- POST
- JSON
- Parameters
- Authentication
- API keys
- Pagination
- Rate limits

Python can later be used to automate API data collection.

Example:

```python
import requests

response = requests.get(API_URL)
data = response.json()
```

## 8. Surveys and Forms

When the required data does not already exist, an analyst or organization may collect it directly.

Examples:

- Google Forms
- Microsoft Forms
- Survey platforms
- Internal company systems

Example question:

> How satisfied are you with our delivery service?

Possible scale:

```text
1 = Very dissatisfied
2 = Dissatisfied
3 = Neutral
4 = Satisfied
5 = Very satisfied
```

The responses become a dataset.

---

## 9. Web Data

Websites can contain useful information such as:

- Public statistics
- Product information
- Public listings
- Public documents
- Prices
- Other publicly available information

There are two major approaches:

### Official API

Usually preferable when an appropriate API exists.

### Web Scraping

A program extracts information from webpages.

Common Python tools:

- Requests
- BeautifulSoup
- Scrapy
- Selenium
- Playwright

Important:

Publicly accessible information is not automatically free to scrape or reuse without restrictions.

Before collecting web data, consider:

- Terms of Service
- robots.txt
- Copyright
- Privacy
- Rate limits
- Authentication
- Applicable laws

Prefer:

**Official API → Official downloadable dataset → Permitted scraping**

## 11. Data Collection Is Not Just "Getting Data"

Before collecting data, ask:

### 1. What question am I trying to answer?

Bad:

> Collect sales data.

Better:

> Why did monthly sales decrease?

### 2. What variables are required?

For example:

```text
date
product
region
quantity
price
discount
revenue
```

### 3. Where can the variables be obtained?

Example:

```text
Orders        → SQL database
Customers     → CRM
Marketing     → API
Returns       → SQL database
Economic data → Government dataset
```

### 4. Is the source reliable?

Consider:

- Who produced the data?
- How was it collected?
- How frequently is it updated?
- Is the methodology documented?
- Does it contain missing information?
- Is it representative?
- Could it contain bias?

### 5. Am I allowed to use it?

Check:

- License
- Terms of use
- Privacy requirements
- Copyright
- Data-sharing restrictions

---

## 12. Data Quality Begins During Collection

Good data collection makes later cleaning easier.

Example of problematic data:

```text
Age
21
22
twenty-three
23 years
-5
200
```

Another example:

```text
Gender
Male
M
male
MALE
```

These problems will need to be addressed during **Role 2 — Processing & Cleaning Data**.

Therefore:

> Good data collection reduces downstream data-quality problems.

---

## 13. Documentation and Metadata

A professional analyst should document where the data came from.

Example:

```text
Dataset:
Customer Orders

Source:
Company SQL Database

Collected:
September 27, 2026

Purpose:
Analyze monthly sales

Fields:
order_id
customer_id
date
product
quantity
revenue

Last Updated:
September 2026

License / Permission:
Internal company data

Notes:
Raw data preserved before cleaning
```

Documentation helps with:

- Reproducibility
- Traceability
- Data governance
- Collaboration
- Future analysis

## 14. Real-World Data Collection Example

### Business Question

> Why did revenue decrease in September?

### Step 1 — Identify required data

```text
Orders
Customers
Products
Marketing
Returns
```

### Step 2 — Identify sources

```text
Orders       → SQL database
Customers    → CRM
Products     → SQL database
Marketing    → API / marketing platform
Returns      → SQL database
```

### Step 3 — Extract the data

```text
SQL → orders.csv
SQL → customers.csv
API → marketing.json
SQL → returns.csv
```

### Step 4 — Store and document

Record:

- Source
- Collection date
- Query / API used
- File name
- Dataset version
- Relevant metadata

### Step 5 — Move to the next role

The collected data now goes into:

**Role 2 — Processing & Cleaning Data**

## 16. What We DON'T Need Yet

For Role 1, we do NOT need to focus on:

- Statistics
- Power BI
- Tableau
- Advanced data visualization
- Advanced statistical analysis
- Machine Learning

These will become relevant later.

### Roadmap

```text
Role 1 → Collecting Data
Role 2 → Processing & Cleaning Data
Role 3 → Analyzing Data + Statistics
Role 4 → Visualizing & Reporting
Role 5 → Making Recommendations
Role 6 → Using Powerful Tools
Role 7 → Working with Teams
```

Power BI and Tableau will mainly become important around **Role 4 — Visualizing & Reporting**.

          ↓             ↓             ↓
          └─────────────┼─────────────┘
                        ↓

                        ↓

                        ↓
             ROLE 3: ANALYZE
                        ↓
          ROLE 4: VISUALIZE & REPORT
                        ↓
         ROLE 5: RECOMMENDATIONS
